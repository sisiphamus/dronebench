A bench where AI agents design drones and get checked.

DroneBench takes a small electric fixed-wing aircraft, checks that it can fly, and scores it. An agent edits the design, DroneBench accepts or rejects every change with a reason, and you watch the whole run live.

The loop

Every agent gets the same environment: a design folder, a brief, and a few commands. It never edits files by hand, so every change is judged.

1 · EDIT

Change the aircraft

Remove, swap, scale or move parts, or turn a design knob (span, tail, spar, motor, prop, battery) and rebuild the whole aircraft.

2 · ANALYSE

Check that it flies

Lift and drag, motor, prop and battery, spar strength, stability, wiring, and whether every part is still attached to the airframe.

3 · JUDGE

Accept or reject

Fails any check: rejected, with the check, the value and the limit. Scores lower: rejected. Otherwise the design moves forward.

4 · EXPLAIN

Every part, justified

Each part is removed in a copy and the aircraft re-analysed, so the report says which parts are required, helpful or dead weight.

Hard to game

The first Claude run scored higher by deleting the rudder, all wiring and the motor mounts. Those now fail the gate, and the tests keep it that way.

ShortcutWhat stops it
Delete the wiring to save weightharness check: minimum wire mass for the ESCs, servos and flight controller
Delete the rudder and its servocontrol check: roll, pitch and yaw surfaces required
Delete the motor pods or a fuselage sectionairframe check: every part must stay attached to one airframe
Invent a 400 Wh/kg batteryplausibility limits clamp agent-supplied specs and flag them
Remove genuinely dead weight (ballast, spare GPS, armor)allowed, and it is where most of the gain comes from

Run it

Python 3.11+. Claude Code is optional; any script can drive the same commands.

# install
git clone https://github.com/sisiphamus/dronebench && cd dronebench
uv venv && uv pip install -e .

# make a workspace and watch it live
dronebench init runs/demo --fixture falcon_v2 --steps 12
dronebench serve runs/demo --open

# in another terminal: let an agent iterate
dronebench run runs/demo --agent claude        # Claude Code, headless
dronebench run runs/demo --agent random        # random-search baseline to beat

# or drive it by hand, exactly as an agent does
dronebench status runs/demo
dronebench try runs/demo --ops ops.json --note "ballast is dead weight"
dronebench build runs/demo --set wing.span_mm=2200 --note "more span"

How much to trust it

The physics is analytic: lift slopes, drag build-up, a motor, prop and battery model, a cantilever spar, neutral-point stability. It is meant for ranking designs against each other, with an error of about ±15%. It is not a certificate of airworthiness, and the Falcon V2 planform is a documented assumption.
