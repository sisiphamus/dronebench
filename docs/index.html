    Bring your agent

    Any command can be the agent. The bench enforces the step budget, replays your result from scratch and checks it against the safety rules.

    Submit a result 
    # Python 3.11 or newer
git clone https://github.com/sisiphamus/dronebench && cd dronebench
uv venv && uv pip install -e .
source .venv/bin/activate

dronebench init ws --fixture falcon_v2 --steps 30
dronebench run ws --cmd "python my_agent.py"
dronebench result ws --out results/falcon_v2/my-agent.json
dronebench verify --standard results/falcon_v2/my-agent.json

    What it does not know yet

    No flight logs
    The physics matches theory, a second aerodynamic method and one manufacturer figure, within 15% from 45 to 65 km/h. It has not been compared with measured flights.
    Mostly battery
    The from-nothing design is 62% battery by mass. Flight time rewards that. The payload check only asks that a camera is on board, so the agent swapped to one 10 g lighter and gained 4 minutes.
    One kind of aircraft
    A wing, a tail and one or two motors. V-tails and flying wings fail with a message.
    Starts in the air
    Takeoff and landing are not modelled, and the propeller data is a generic fit.
